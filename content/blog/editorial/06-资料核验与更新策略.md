# 资料核验清单与更新策略

## 官方资料优先级
1. 官方仓库 README、版本化文档、Release、CHANGELOG、LICENSE。
2. 官方包管理器元数据与示例项目。
3. 第三方文章仅作为线索，不直接替代执行与版本验证。

## 近期特别容易写错的地方
- Codex Host 的 Browser Use（浏览器）与 Computer Use（桌面）、OpenAI Computer Use API 是不同接入层。
- Playwright Test / CLI / MCP / Test Agents 是不同工具与能力层，不能合成一个“安装命令”。
- Stagehand v2/v3/v4 的方法层级可能有差异，例子必须锁版本。
- Browser Use `--cli-mcp` 与旧版 MCP 具不同工具面；需要依据当前官方迁移说明。
- ego-browser Skill 依赖 ego lite 应用；不要当作通用 Browser Adapter。
- BrowserGym/AgentLab 评价 Agent 能力，不直接提供生产业务回归断言。
- Skyvern 的 AGPL-3.0、自托管、遥测、模型/云服务依赖应单独核验。
- 浏览器白名单不等于 OS 层出口防火墙。
- @axe-core/playwright 的 package、Node 要求和版本会变化，必须当前核验。
