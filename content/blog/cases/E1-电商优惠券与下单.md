# E1｜电商优惠券与下单：统一教学业务契约

> 状态：示例合同，**不是任何真实电商业务的规则**；实践时以已有 v2.0 Demo 的 `contracts/cases/E1.yaml` 为唯一详细规则基线。此处是写作摘要。

## 固定规则
Demo：购物车小计达到 100 元时 C20 抵扣 20 元；99 元不得享受优惠；相同幂等键不能创建多个有效订单

## 跨工具复用的测试任务
1. 在 99 元与 100 元边界切换优惠券并检查 UI 与报价 API 一致
2. 选择优惠券后修改数量、刷新或返回购物车并重新计算
3. 快速重复提交订单，读取只读订单账本验证无重复订单

## 独立业务 Oracle
`checkout_quote + order_ledger + coupon_ledger`。验证页面状态前，必须先建立服务端只读证据、事件日志或账本，再关联截图与浏览器 Trace。

## 风险与误报边界
- 核心风险：金额漂移、重复下单、优惠券状态不一致。
- 安全范围：禁止真实支付、真实发货和生产券核销。
- 只看到 UI 异常时标记为 `Suspected`，只有符合业务契约、有独立证据并复现后才可 `Confirmed`。
