# M1｜会员等级升级与降级：统一教学业务契约

> 状态：示例合同，**不是任何真实电商业务的规则**；实践时以已有 v2.0 Demo 的 `contracts/cases/M1.yaml` 为唯一详细规则基线。此处是写作摘要。

## 固定规则
Demo：普通/银/金/铂金；银升金解锁金卡专享，金降银后旧会话不得继续新建金卡专享订单；旧领券按自身有效期保留；UI 30 模拟秒内同步

## 跨工具复用的测试任务
1. 使用测试事件将银卡升级为金卡，验证展示与服务端鉴权
2. 模拟金卡降银卡，不刷新旧 Token 检查高级权益无法再次使用
3. 重复或乱序投递等级事件，验证等级不倒退且历史权益策略正确

## 独立业务 Oracle
`membership_authorization + membership_events + entitlement_ledger + fake_clock`。验证页面状态前，必须先建立服务端只读证据、事件日志或账本，再关联截图与浏览器 Trace。

## 风险与误报边界
- 核心风险：降级越权、旧会话、缓存陈旧、历史权益误删。
- 安全范围：只能变更测试用户的 Fixture 会员状态。
- 只看到 UI 异常时标记为 `Suspected`，只有符合业务契约、有独立证据并复现后才可 `Confirmed`。
