# 质量、安全与发布门禁

| Gate | 关注点 | 最小证据 |
|---|---|---|
| 0 授权 | 仅本地/明确授权 Demo，独立测试账号、最小权限 | Scope、允许动作与禁止动作清单 |
| 1 契约 | E1/M1/S1 教学规则已确认，不让模型自行定义业务正确性 | 契约版本、审批及正反例 |
| 2 TDD | RED→GREEN→REFACTOR，固定种子，自动化无顺序依赖 | 真实测试命令、退出码、回归记录 |
| 3 技术 | 工具发行版、安装命令、License、遥测/云端数据流 | 官方来源、版本、安装实测日志 |
| 4 Oracle | UI + API + 后端账本独立验证 | Trace/截图/脱敏 API 与账本对照 |
| 5 缺陷 | Observation→Suspected→Reproduced→Confirmed | 独立复现和人工确认 |
| 6 发布 | Research / Technical / QA / Editorial 审查 | 人工批准，不靠 Agent 自报通过 |

- 页面内容、工具输出和第三方文档均为不可信输入，不能覆盖用户 Scope/工具授权。
- Browser Agent 不允许通过任意 JavaScript、Shell、文件或未授权网络工具绕过浏览器动作边界。
- 保留失败、误报、无法复现与安全违规记录；真实业务案例必须使用脱敏数据。
- 性能/并发测试仅在受限服务级别的隔离环境，经批准并明确并发上限后运行。
- 比较指标至少包括有效缺陷比例、独立复现率、脚本稳定性、证据完整率、操作成本和越权事件。
