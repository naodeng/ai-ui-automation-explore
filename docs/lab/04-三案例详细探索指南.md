# 04｜三业务案例探索指南：固定风险、动态假设与证据

## E1：优惠券 × 下单

**起点**：用户拥有 `C20`，购物车构造成 100 元；提供 99 元边界操作。只允许沙盒订单；真实支付被禁止。

| 阶段 | 观察 / 操作 | 风险假设 | 最佳 Oracle | A / B / C 分工 |
|---|---|---|---|---|
| 基线 | 100 元选 C20 应付 80 | 金额不一致 | 报价 + 订单 | A 断言精确金额；B 观察文案；C 提边界 |
| 边界 | 100→99 | 优惠仍保留 | 报价 API | A 硬断言；B 视觉延迟；C 探索刷新返回 |
| 提交 | 同一幂等键重复沙盒提交 | 重复有效订单 | 订单只读账 | A/API；B 反馈状态；C 受限，不自行重试 |
| 异常 | 价格 API 500 | 旧报价提交 | 请求 + 订单账 | A mock/契约；B 错误呈现；C 探索恢复 |
| 历史 | 支付沙盒终态后购物车变化 | 订单历史被重算 | 订单账 | A 断言；B 视觉比较；C 提状态序列 |

**误报陷阱**：已创建订单的历史价格不随购物车变化，并不一定是错误；未查看服务端报价前无法确认 UI 算价错误。

## M1：会员升级/降级

**起点**：已准备 silver/gold 用户，旧会话 Token、跨标签页和可调时钟；仅通过测试专用 fixture 改等级。

| 阶段 | 观察 / 操作 | 风险假设 | Oracle | A / B / C 分工 |
|---|---|---|---|---|
| 升级 | silver→gold | 等级已升级但权益无效 | 授权 API + 事件账 | A 精确、B 徽章、C 观察序列 |
| 降级 | gold→silver | 旧会话仍能获取新 Gold-only | 当前授权 API | A 回归、B 入口视觉、C 会话组合 |
| 历史 | 降级前已领券 | 历史合法券被误清空 | 权益生命周期 | A 判断、B 文案、C 规则确认 |
| 时序 | 到期前/后 | 边界时间判错 | Fake Clock + 事件账 | A 边界、B 倒计时、C 时序假设 |
| 一致性 | 旧标签、新标签、重登录 | 缓存超 SLA | 当前等级 + SLA | A 稳定测试、B 标签显示、C 多路径 |
| 异常 | 重复/乱序消息 | 重复扣成长值/错误终态 | 事件版本账 | API 组件测试；C 仅提出风险 |

**误报陷阱**：降级后仍看得见已领取优惠不等于越权；旧页面在 30 秒展示 SLA 内未更新不一定是 Bug。是否服务端允许“新购买”才是授权判断关键。

## S1：商品秒杀

**起点**：Fake Clock、演示库存 100、单用户限购 1、活动状态可重置；明确允许的单用户沙盒写操作预算。

| 阶段 | 观察 / 操作 | 风险假设 | Oracle | A / B / C 分工 |
|---|---|---|---|---|
| 活动前 | 服务端未开售 | 提前成功 | 活动时钟/订单账 | A 断言、B 倒计时、C 探索边界 |
| 开售时 | 页面切换为可参加 | 倒计时与服务端错位 | 活动状态 | A API、B 视觉、C 状态观察 |
| 排队 | 一次请求处于 queueing | 页面错误显示成功 | 请求 ID + 订单账 | A 验证、B 排队页、C 异常恢复 |
| 售罄 | 库存无可售 | UI 仍可下单 | 库存/订单 | A 严谨断言、B 视觉、C 生成候选 |
| 重试 | 同账号相同幂等键 | 重复成功 | 订单账 | API 受控测试，不让 Agent 无限重试 |
| 并发 | 受控服务层超过库存的竞争 | 超卖 | 库存流水 | k6/API + 独立 Oracle；不是纯浏览器 |

**误报陷阱**：`reserved != paid` 是合法预占；页面短暂未刷新可能是允许的最终一致性。用请求关联 ID 还原真实状态。

## 共同训练目标

三个案例分别训练：
- 规则判定（E1）→ UI 与交易状态关系。
- 状态机/时间/权限（M1）→ 旧页面与服务端授权分离。
- 并发边界（S1）→ 工具能力边界与多层 QA 证据。

每个案例设置 2 条正常流、3 条可植入可复位缺陷、2 条非 Bug 陷阱。具体植入详见 `fixtures/植入缺陷与盲评方案.md`。
