# P4｜B：视觉 AI 探索的价值验证

前置：P3-A 的稳定测试和证据门禁已通过，且已批准模型 Provider 和截图数据流。阅读 `docs/08-方案B-视觉驱动.md`、`docs/12-安全隔离与恢复.md`。

先核对 Midscene 具体版本、文档和真实 API/CLI（不要复制过时示例）。锁定版本，只为**一项有视觉增益的场景**实现最小 PoC，再决定是否扩展三个案例。

按同一 seed 与 viewport 测：
- E1：窄屏券卡/金额/错误提示遮挡与一致性；
- M1：升级降级徽章、权益卡、失效说明、缓存期视觉反馈；
- S1：活动前/排队/售罄倒计时、按钮和错误状态。

所有 AI 视觉判断只能是候选，必须有设计规范/明确 UX 原则（视觉）或 P3 的 Oracle（业务）核查。记录截图/模型版本/费用/重复三轮的成功率。若未获得模型使用批准，只提交可运行的干跑 Mock + 审核报告，不主动上传页面。

交付：`reports/P4_B_REVIEW.md`、新增发现与 P3 重叠比例、误报/成本、数据流和风险。若证明不了增益，建议不引入到 MVP。
