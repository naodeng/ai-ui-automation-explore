# P2-S1｜商品秒杀 Demo：正确性边界与受控并发

阅读 `AGENTS.md`、`contracts/cases/S1.yaml`、`docs/03-业务规则与真相源.md`、`docs/04-三案例详细探索指南.md`、`docs/12-安全隔离与恢复.md`。

本轮只实现本地可复位的秒杀演示：活动前/open/queueing/sold_out UI、Fake Clock、100 件库存、单用户限购 1、请求幂等、预占/已售/释放流水、只读 FlashSaleOracle。**所有流量限制在 localhost 演示服务，不访问生产或公共站点**。

TDD：
- RED：未开始活动前不能购买成功；重复相同幂等键不能出现 2 个有效订单；单账号成功数量 ≤1；有效已售/预占与库存账满足演示定义的守恒式；取消/超时释放幂等。
- GREEN：实现最小 API 与 UI。不要加入真实支付和生产风控。
- REFACTOR：使用固定 clock/seed、重置与随机执行顺序，结果可重复。
- 另外设计**独立的服务级受控并发测试**，明确最大并发上限、窗口和审批。未批准不得运行高负载；不得以浏览器快速点击证明没有超卖。

每个测试结果附 request_id、order_id、stock_ledger checksum。浏览器 Agent 默认只允许观察与单个授权请求。

交付：`reports/P2_S1_REVIEW.md`、库存一致性说明、测试命令/退出码、真实 Evidence、未验证风险。不引入未授权压测或第三方系统。
