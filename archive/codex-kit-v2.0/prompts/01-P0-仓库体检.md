# P0｜仓库与安全准备审查（交给 Codex）

你现在只负责 P0。阅读 `AGENTS.md`、`00_START_HERE.md`、`docs/01-项目章程与范围.md`、`docs/02-端到端执行流程.md`、`docs/17-资料与工具核验.md`、`docs/18-风险登记与阻断项.md`。

完成以下检查：
1. 当前仓库是否包含本包全部文件？运行 `python3 scripts/validate_kit.py`，列出校验项/失败项。
2. 检查 Git、Node、包管理器、Playwright、浏览器、macOS 实际版本（只读检查）；不要求立即安装。
3. 核对官方 Playwright CLI/Test Agents、Midscene、Agentic Test Explorer 的公开版本、命令、许可证及是否外传数据；引用 URL 和核对日期。不能把未经证实的命令写成可运行脚本。
4. 从 `contracts/cases/` 的演示规则抽取待确认问题，输出 Rule→Risk→Oracle 追踪矩阵。
5. 制定本地 localhost 沙箱、测试账号、网络隔离、凭据、动作审批、安全停机设计；禁止生产访问。
6. 提交建议目录结构、锁版本策略与 P1 TDD 任务清单；避免引入多个 Browser Adapter、云 DB、K8s、多 Agent。

输出 `reports/P0_READINESS.md`，必须包含：Scope、已实际检查、工具兼容性、风险表、架构 ADR 待审批项、GO/Conditional GO/No-Go、下一阶段 RED 测试列表、命令与真实退出码。未运行的项目写 NOT RUN。
