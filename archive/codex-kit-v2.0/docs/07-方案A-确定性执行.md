# 07｜方案 A：Playwright CLI + Test + Oracle（第一期必做）

## 目标

将 Codex 用于**探索计划和辅助操作**，但最终的回归断言尽量由稳定的 Playwright Test + API Oracle 执行。先确认工具版本，再生成代码；不要声称单次 AI 交互就等于可维护回归。

## 分步实施

1. P0 核查 Playwright 官方文档，锁定版本，使用仓库 `package.json` 与 lockfile。
2. P1 定义统一 `TestContext {caseId, runId, seedId, clock, allowedOrigin}`。
3. P2 为 E1/M1/S1 完成可重置 Demo，且执行前后状态有 checksum。
4. P3 先写 Playwright **确定性断言**，再给 AI 浏览器探索 Charter。
5. 每次执行保存 Trace（失败保留）、截图、请求 ID 及独立 Oracle 响应摘要。
6. 候选问题至少独立复现一次；需要真实状态检查的 Bug 必须由只读 Oracle 辅证。

## 三案例最小回归矩阵

| 案例 | P0 必跑 | 需要的独立证据 |
|---|---|---|
| E1 | 100→80；100→99 后券失效；相同幂等键重复提交 | 报价、订单与券账 |
| M1 | silver→gold；gold→silver；旧会话 Gold-only 操作被拒 | 当前等级、授权结果、事件版本 |
| S1 | 未开始禁止买；开售合法单账号成功；同账号重复限购 | 活动时钟、订单、库存账 |

## Playwright 代码示意（不是当前包已实现代码）

```typescript
import { test, expect } from '@playwright/test';

test('E1: coupon threshold is enforced by backend', async ({ page, request }) => {
  // Setup/cleanup MUST be implemented via authorized, local test fixtures.
  // Use stable test IDs only after the demo has actually defined them.
  await page.goto('/checkout');
  const payable = page.getByTestId('payable-amount');
  await expect(payable).toHaveText('80.00');
  // Change demo cart total to 99 through a verified UI control.
  // Then use a read-only oracle endpoint; never assume UI alone is authoritative.
  const res = await request.get('/__test/oracle/checkout?run_id=E1_RUN_ID');
  expect(res.ok()).toBeTruthy();
  const oracle = await res.json();
  expect(oracle.payable).toBe(99);
});
```

注意：示意中按钮交互与可执行 fixture 尚未实现；示例只有在相应 seed、UI test-id 与 API 就绪之后才能变成实际通过的测试。请勿复制后声称它是已通过的业务回归。

## TDD 验收

- RED：错误金额、降级越权、重复订单能产生可解释的失败。
- GREEN：正常版本的 9 个 P0 不变量断言通过。
- REFACTOR：不同运行顺序、多次 reset、不同视口运行稳定；断言不会被自动改写以迎合产品行为。
- Evidence：Trace、run manifest、后台只读响应、发现和人工复核状态相互可追踪。

## CLI 实践

官方提供 Playwright CLI 的 Agent 用法以及 `npx playwright init-agents --loop=codex`。但**具体 CLI 子命令必须按锁定版本的 `--help` 确认**，不要在手册混用历史 MCP 的工具名。参考：
- https://playwright.dev/docs/getting-started-cli
- https://github.com/microsoft/playwright-cli
- https://playwright.dev/docs/test-agents
- https://playwright.dev/docs/trace-viewer
