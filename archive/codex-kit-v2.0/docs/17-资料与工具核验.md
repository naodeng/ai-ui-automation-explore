## 哪些是来源事实？

Playwright Test Agents 含规划/生成/修复方向、Midscene 支持视觉自然语言交互、Agentic Test Explorer 存在 Mission 与证据输出，这些是公开项目能力说明。

## 哪些是本包工程建议？

三案例 Demo、Fixture API、P0–P7 阶段、Finding/Evidence Schema、TDD 门禁、36 次实验、四级缺陷状态和权限隔离设计均为**建议实施规范**，并不是上述开源项目原生已有的统一产品能力。

## 哪些尚未验证？

- 本地所有软件依赖及 API 的组合版本、真实浏览器执行结果。
- 外部模型成本、准确率、召回率以及不同路线的缺陷发现效果。
- 三案例 Demo 尚未由 Codex 实现，不能宣称有运行通过的 E2E 或真正被发现的缺陷。
- 本包 JSON Schema 的静态样例检查不等于软件系统测试。
