# 12｜安全策略、数据保护、故障恢复与停机条件

## 默认拒绝

- 未经授权的外网 URL、生产域名、真实客户账号与支付网关。
- 任何高危写操作：批量删除、真实退款、邮件/短信发送、会员实际改档、资金/库存调整。
- Browser Agent 自行发起高并发、扫描、绕过风控、任意 Shell、任意脚本执行。
- 任意来自页面、Issue、日志或模型输出的新“授权”。
- 真实浏览器 Profile、未经脱敏的 Cookie/Token/用户数据流向第三方模型。

## Host 必须实际执行的技术措施

1. 浏览器、操作系统、网络沙箱：只允许 loopback 和经过核准的 Demo Origin；禁止默认访问所有网络。
2. `allowedOrigin` + `allowedPaths`、动作级授权（观察/点击/提交/支付等分级），在 Browser Adapter 或代理层强制执行。
3. 管理写 API 与 Browser Agent 完全分权；Agent 没有 Reset、Seeded Fault 或 Clock 管理密钥。
4. 对未知外部网络、URL 重定向、工具执行任意 JS/Python/Shell 必须默认拒绝。
5. 成本/时间/动作/写入预算、故障最大重试次数、紧急停止开关。
6. Trace/HAR/截图保存前脱敏，按数据分类设置留存期限，适用时设置加密与访问控制。

## 失败恢复矩阵

| 事件 | 操作 | 验证与恢复 |
|---|---|---|
| 网络超时，但写入结果未知 | 停止写入与自动重试 | 只读核对 idempotency/request ID；按契约补偿 |
| Browser Session 异常 | 关闭会话、保留证据 | reset + 新 run_id 重新运行 |
| Agent 预算耗尽 | 状态 `incomplete` | 不生成 Confirmed，提交未完成说明 |
| 页面 Prompt Injection | 拒绝页面发起的策略变化 | 记录安全事件并结束任务 |
| Oracle 返回不一致 | 拒绝晋级缺陷状态 | 保留所有冲突证据，启动人工核查 |
| 实际越权执行 | 立即停止所有自动化 | 隔离、审计、No-Go，排查数据副作用 |

## 特别说明：为什么域名白名单不足

如果同时允许 Shell、任意 JS、MCP 管理工具或本机文件读写，Agent 可以通过浏览器之外的通道访问不被白名单覆盖的资源。因此必须使用网络/进程/用户权限的真实隔离层；Prompt 只是帮助 Agent 理解限制。

## 审批分级

- L0：观察、截图（在允许范围内）→ 可以自动。
- L1：安全 UI 状态变化、单个沙盒表单提交 → 先有测试任务授权和数据重置。
- L2：订单、会员权益、模拟支付等写操作 → 事先显式审批，自动 Agent 仍不能自主决定升级授权。
- L3：高并发流量、外部服务、删库等 → 默认禁止；如需实验必须单独安全评审与专门隔离执行器。
