# 16｜博客发布、示例复盘和持续学习

## 文档使用

- `legacy-v1.0/01-完整科普文章-三案例版.md` 为**原有文章单源**。先保留原始正文，不在不同渠道复制两份产生分叉。
- 技术方案 A/B/C 可作为同系列进阶篇；更新实验结果时只基于真实 Run Evidence，严禁虚构“AI 找到 xx 个 Bug”。
- 网站/公众号统一 Markdown，补充 TOC、可渲染 Mermaid、三案例表格、真实截图（脱敏）。
- 项目过程文档中文，项目主页/AGENTS 英文默认可提供中文版。

## 发布前 Review

- 标明 Demo 规则和植入缺陷是**合成案例**。
- 真实实验须披露环境、版本、执行次数、缺陷分类与测量限制。
- 不夸大 Browser Agent 的服务端并发能力，不把高 Star 当作测试有效性证据。
- 外部工具命令与 API 要重新核对当前锁定版本的官方文档。
- 移除密钥、真实客户信息、未经许可第三方截图。

## 复盘维度

新增质量发现、重复报告、误报、人工审核时间、每次 Run 资源消耗、任务恢复是否可靠、权限拦截是否有效、哪个案例产生最大增益。
