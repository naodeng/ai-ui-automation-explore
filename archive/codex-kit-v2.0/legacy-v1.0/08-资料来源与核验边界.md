# GitHub / 官方文档来源与核验边界

> 核查日期：2026-11-23。以下引用用于支撑工具的**公开产品能力**；文件包内三业务案例、状态机、测试流程、评价模型属于本文原创的 QA 工程设计和演示，未在真实系统运行。

## 一、执行器与浏览器调试

1. **Microsoft Playwright CLI**：https://github.com/microsoft/playwright-cli 。README 列出了官方安装 `npm install -g @playwright/cli@latest`、`playwright-cli install --skills`、open/snapshot/requests/console/tracing 等命令。支持会话、截图、Trace。实际 CLI 子命令请以锁定版本 `--help` 为准。
2. **Playwright Test Agents**：https://playwright.dev/docs/test-agents 。官方提供 planner / generator / healer，Codex 初始化示例 `npx playwright init-agents --loop=codex`。不能把 Healer 的自动修改当作业务预期自动变更审批。
3. **Playwright Trace Viewer**：https://playwright.dev/docs/trace-viewer 。可以检查动作时间线、快照、网络等信息；敏感 Trace 需在受控环境保存。
4. **Vercel agent-browser**：https://github.com/vercel-labs/agent-browser 。README 包含 `--allowed-domains`、`--action-policy` 等安全选项及浏览器网络观察能力；安全开关需要显式配置。
5. **Microsoft Playwright MCP**：https://github.com/microsoft/playwright-mcp 。MCP 浏览器能力适合 Host 集成，但 MCP Server 本身不是沙箱边界。
6. **Chrome DevTools MCP**：https://github.com/ChromeDevTools/chrome-devtools-mcp 。Console / Network / Performance / Trace 诊断工具；可用高权限工具必须独立约束。
7. **Selenium**：https://github.com/SeleniumHQ/selenium ；**Puppeteer**：https://github.com/puppeteer/puppeteer 。可作为自建 Adapter 或既有栈，非自带测试判断 Agent。

## 二、视觉与 Agent

8. **Midscene.js**：https://github.com/web-infra-dev/midscene 。README 明确视觉驱动、`aiAct` / `aiQuery` / `aiAssert` 及相关平台支持。YAML 例子参考 https://github.com/web-infra-dev/midscene/blob/main/apps/site/docs/en/automate-with-scripts-in-yaml.mdx 。
9. **Stagehand**：https://github.com/browserbase/stagehand 。Act / Observe / Extract 及不同版本 Agent 支持。v2/v3/v4 API 可能不同，不能混用旧文档代码。
10. **Browser Use**：https://github.com/browser-use/browser-use 。CLI/MCP 版本持续变化，新 `--cli-mcp` 与旧工具名不可直接混用；使用时应固定版本并检查迁移文档。
11. **Skyvern**：https://github.com/Skyvern-AI/skyvern 。浏览器 Agent 与工作流，适合后续对比，需独立审查许可与数据流。
12. **Agentic Test Explorer**：https://github.com/srbarrios/agentic-test-explorer 。官方声明其为 PoC；README 描述测试角色、LangGraph、Playwright、`traces.log`、`test_report.md`、`action_tape.jsonl`、`reproduction_*.spec.ts`。Mission 格式见 https://github.com/srbarrios/agentic-test-explorer/blob/main/missions/README.md 。
13. **BrowserGym**：https://github.com/ServiceNow/BrowserGym 。是 Web 任务与浏览 Agent 评估环境，并不直接证明真实业务缺陷发现率。

## 三、辅助验证

14. **Playwright Network / Mock**：https://playwright.dev/docs/network 以及 https://playwright.dev/docs/mock 。支持监控、修改和 Mock 网络流量；Mock 结果不能当作真实后端完整性证据。
15. **axe-core**：https://github.com/dequelabs/axe-core 。自动化可访问性检查引擎；需补人工键盘、阅读器等评估。
16. **Grafana k6 Scenarios**：https://grafana.com/docs/k6/latest/using-k6/scenarios/ 。通过 arrival-rate 等执行器模拟不同负载类型；适合受控验证秒杀并发，但本包没有执行压测。
17. **OWASP Prompt Injection**：https://genai.owasp.org/llmrisk2023-24/llm01-24-prompt-injection/ 。页面文本等不可信内容可能诱导 Agent 采取未经授权动作，因此工具权限和策略必须独立于模型推理。

## 四、明确未验证事项

- 未测试任何用户业务仓库，未验证实际 Demo 页面、具体 API 路径、Test ID、真实会员规则或秒杀库存行为。
- 未对 A/B/C 三组执行同场对照，缺陷数、召回率、Precision、成本和安全成功率均未实测。
- 未在本地安装所有工具或做版本兼容实验。
- 部分项目拥有付费服务/外部模型能力，实际数据流和许可需逐版本复核。
- 实例中的 `example.invalid` 是保留的无效域名占位；任何测试前需替换为已授权 staging。
