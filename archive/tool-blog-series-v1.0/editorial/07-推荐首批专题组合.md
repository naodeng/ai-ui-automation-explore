# 推荐先发布的 8 篇（并非工具排名）

第一梯队优先形成「可复制、可信」的 UI 自动化基础教程：
1. Playwright Test：确定性基线是什么。
2. Playwright CLI：如何用 Codex 操作页面并生成测试资产。
3. Playwright MCP：MCP 形式和安全边界。
4. agent-browser：Snapshot/Ref 交互与回归资产转换。
5. Codex Computer Use：视觉验证的优势与 Host 边界。
6. ego-lite：共享浏览器与真实会话风险。
7. Midscene.js：视觉 UI 自动化补充。
8. Playwright Test Agents：计划/生成/修复，以及如何不掩盖真 Bug。

**每一篇都能独立阅读**，但建议互相链接已完成的基础文章。第二轮再根据三个 Demo 的真实实验结果安排 Stagehand、Browser Use、Skyvern 和复杂 Agent 篇。
