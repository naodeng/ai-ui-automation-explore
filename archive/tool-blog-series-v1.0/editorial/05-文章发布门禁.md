# 文章发布门禁 / Quality Gate

## Gate R — Research
- [ ] 官方 README/Docs/Release/License 已核查（核查日期 + 固定版本/commit）
- [ ] 与其他工具相似之处和不同之处准确
- [ ] 安装、MCP、SDK 代码与当前版本一致
- [ ] 未把「工具可以操作浏览器」夸成「自动保证质量」

## Gate T — Technical Reproduction
- [ ] 本地 Mac 环境或指定环境完整复现安装、Quick Start，附命令和退出码
- [ ] 有会话/数据重置证明
- [ ] 主案例具备自动化断言和独立业务 Oracle（不支持则明确局限）
- [ ] 保存匿名化的截图、Trace/Network/日志或清楚说明工具不支持
- [ ] 失败路径和边界条件得到演示

## Gate Q — QA Method
- [ ] 预期业务规则有来源，不依赖模型臆测
- [ ] 结果与缺陷分级清楚，确认 Bug 有证据及独立复现
- [ ] E1/M1/S1 三案例至少主案例展开，其余简要阐述迁移边界
- [ ] 有自动化维护、CI、Flaky、持续回归的适用性判断

## Gate S — Safety & Data
- [ ] 仅授权环境，无生产写操作、无真实支付和未授权秒杀压测
- [ ] Cookie/Token/个人信息/账单信息脱敏
- [ ] 云端模型或浏览器的数据流与许可证已复核
- [ ] 高权限 JavaScript/任意代码/终端执行在隔离环境使用

## Gate P — Publishing
- [ ] 语言适合初学者但关键术语准确
- [ ] 本次文章与之前已发布内容没有自相矛盾
- [ ] FAQ 有准确解答；复杂限制不偷换为功能优势
- [ ] Markdown 正文、摘要、TOC、内部链接、引用核对完成
- [ ] 人工审批将 `status` 改为 `published`

> Gate 未通过时，发布为研究笔记或明确标「未实测」，不能包装为实测教程。
