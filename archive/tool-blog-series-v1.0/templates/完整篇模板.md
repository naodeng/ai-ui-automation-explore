# 完整篇模板（面向可持续 UI 自动化）

- 标题：`[工具名称] 实战：从安装到 [核心优势] 的 UI 自动化测试`
- 开场：一个完整的生活化问题 → QA 真实痛点 → 本文验证结果/待实测。
- 目录、适用人群、能力定位、原理边界。
- 环境准备与准确安装命令（版本固定）+ 安装失败记录。
- 五分钟 Quick Start（可复制，真实执行）。
- 主案例（E1/M1/S1）：业务规则、用例、操作、断言、截图和后端 Oracle。
- 扩展案例 1/2：说明适用和不适用之处，不重复完整流程。
- 探索 → 自动化资产：Script、Test Runner、Fixture、Trace、CI、Flaky。
- 进阶：版本相关高级能力 + 失败恢复 + 维护策略。
- 安全：域名/动作权限、隐私、数据生命周期、工具高权限。
- FAQ：5–8 个工具特有的问题。
- 对照：什么时候用它、什么时候用 Playwright、何时需要其他工具。
- 参考资料与核验时间、测试环境和未实测范围。
