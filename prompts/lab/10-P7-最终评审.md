# P7｜终审、缺陷回归化与发布决策

输入：P0–P6 的所有 Review、Evidence 与 Run Manifests；`docs/10-证据与缺陷治理.md`、`docs/18-风险登记与阻断项.md`、`templates/Go-NoGo决策.md`。

请审核：
- 规则、风险、测试义务和证据是否能从需求追踪到实际 Run？
- E1/M1/S1 每一条 P0 不变量是否有独立验证？
- AI 候选发现是否被复现，是否由人签字才升为 Confirmed？
- 植入缺陷 Ground Truth 是否泄漏给测试 Agent？
- 是否有未批准 URL/写操作/负载/数据外传？
- 费用、重复执行稳定性、误报与人工复核工时是否透明？
- 已确认缺陷是否转化为稳定 Playwright/API 回归资产？

把未达到条件的结果判 `CONDITIONAL GO` 或 `NO-GO`，不能为了发表文章降低门禁。输出 `reports/P7_FINAL_REVIEW.md`、`templates/Go-NoGo决策.md` 的填写建议、迁移建议与文章可公开的事实清单。

最后输出“已证实 / 假设 / 尚未验证”三栏，不允许虚构缺陷发现率、复现率、真实故障或企业采用结论。
